# はじめてのセットアップガイド

プログラミングの知識がなくても進められるよう、画面の操作を1つずつ説明します。
所要時間の目安: ステップ1が約10分、ステップ2(ドライブ同期を使う場合のみ)が約15分。

---

## ステップ1: アプリをインターネットで使えるようにする (GitHub側の設定)

アプリのプログラムはGitHubに保存されています。以下の設定をすると、
`https://kurigorira.github.io/clau-Household-finances/` というURLでアプリが使えるようになります。

### 1-1. プルリクエストをマージする

「プルリクエスト」は、プログラムの変更を取り込むための確認画面のようなものです。

1. ブラウザで https://github.com/kurigorira/clau-Household-finances/pull/1 を開く
2. ページ下の方にある **「Ready for review」** という緑のボタンを押す
   (これは「下書き」状態を解除する操作です)
3. 次に表示される **「Merge pull request」** という緑のボタンを押す
4. **「Confirm merge」** を押す
5. 「Pull request successfully merged」と表示されたら完了

### 1-2. GitHub Pages (無料のWebサイト公開機能) をオンにする

1. https://github.com/kurigorira/clau-Household-finances を開く
2. 上のタブから **「Settings」**(歯車のアイコン)をクリック
3. 左側のメニューから **「Pages」** をクリック
4. 「Build and deployment」の「Source」というプルダウンを **「GitHub Actions」** に変更する
   (保存ボタンはありません。選ぶだけで設定されます)

### 1-3. 公開されるのを待って、アプリを開く

1. 上のタブから **「Actions」** をクリック
2. 「Deploy to GitHub Pages」という項目が動いています。緑のチェックマーク ✅ になるまで1〜2分待つ
   - もし1-1のマージを先に済ませていて何も動いていない場合は、Actionsの画面で
     「Deploy to GitHub Pages」→「Run workflow」を押すと手動で開始できます
3. ブラウザで **https://kurigorira.github.io/clau-Household-finances/** を開く
4. 「栗原家 家計簿」の画面が表示されたら成功!

### 1-4. スマホのホーム画面に追加する (アプリのように使える)

- **iPhone (Safari)**: 上記URLを開く → 画面下の共有ボタン(四角に↑) → 「ホーム画面に追加」
- **Android (Chrome)**: 上記URLを開く → 右上の「⋮」→「ホーム画面に追加」(または「アプリをインストール」)

これで普通のアプリと同じようにアイコンから起動できます。ご家族のスマホでも同じ手順でどうぞ。

## ステップ2: Googleドライブ同期の設定 (複数の端末で使う場合)

この設定をすると、ご夫婦それぞれのスマホやPCで同じ家計簿データを使えます。
**1台の端末でしか使わない場合は、このステップは飛ばしてOKです。**

Googleの決まりで、Driveにデータを保存するアプリには「クライアントID」という
許可証のような文字列が必要です。無料で発行できます。発行作業は**家族の代表者が1回だけ**行えば大丈夫です。

### 2-1. Google Cloud Console でプロジェクトを作る

1. https://console.cloud.google.com/ を開き、普段使っているGoogleアカウントでログイン
   (初回は利用規約への同意画面が出るので同意して進む)
2. 画面上部の **「プロジェクトの選択」→「新しいプロジェクト」** をクリック
3. プロジェクト名に「kakeibo」など好きな名前を入れて **「作成」**
4. 作成後、画面上部のプロジェクト名が「kakeibo」になっていることを確認
   (なっていなければ「プロジェクトの選択」から選ぶ)

### 2-2. Google Drive API をオンにする

1. 左上の「≡」メニュー → **「APIとサービス」→「ライブラリ」**
2. 検索欄に **「Google Drive API」** と入力して検索
3. 「Google Drive API」をクリック → **「有効にする」** ボタンを押す

### 2-3. 同意画面(アプリの名前とユーザー)を設定する

1. 「≡」メニュー → **「APIとサービス」→「OAuth同意画面」**
   (画面によっては「Googleの認証プラットフォーム」→「ブランディング」という名前になっています)
2. 初回は設定ウィザードが開きます:
   - アプリ名: 「栗原家家計簿」など
   - ユーザーサポートメール: 自分のGmail
   - 対象(User Type): **「外部」** を選択
   - 連絡先メール: 自分のGmail
   - 作成/保存で完了
3. **テストユーザーを追加する** (ここが大事!)
   - 「対象」または「テストユーザー」(Audience / Test users)の画面を開く
   - **「+ ADD USERS」** で、**同期に使うGoogleアカウントのGmailアドレス**を追加して保存
   - ※アプリは「テスト」状態のままで大丈夫です。「公開」や審査は不要です

### 2-4. クライアントIDを発行する

1. 「≡」メニュー → **「APIとサービス」→「認証情報」**
2. 上の **「+ 認証情報を作成」→「OAuthクライアントID」** をクリック
3. アプリケーションの種類: **「ウェブアプリケーション」**
4. 名前: 「kakeibo-web」など何でも可
5. **「承認済みのJavaScript生成元」の「+ URIを追加」** に次を入力:
   ```
   https://kurigorira.github.io
   ```
   ※最後に `/clau-Household-finances` は**付けません**。`https://kurigorira.github.io` だけです
6. **「作成」** を押す
7. 表示される **「クライアントID」**(`数字-文字列.apps.googleusercontent.com` という形式)をコピーする
   (あとから「認証情報」の画面でいつでも見られます)

### 2-5. アプリにクライアントIDを設定して同期する

1. アプリ(https://kurigorira.github.io/clau-Household-finances/)を開く
2. **「設定」タブ →「ドライブ同期」** を開く
3. コピーしたクライアントIDを貼り付けて **「Googleにログインして同期」** を押す
4. Googleのログイン画面が出るので、**2-3でテストユーザーに追加したアカウント**でログイン
   - 「このアプリはGoogleで確認されていません」と出たら「続行」を選んでOK
     (自分で作ったアプリなので問題ありません)
5. 「✓ 初回アップロード完了」と出たら成功!

### 2-6. 2台目以降の端末をつなぐ

1. その端末でアプリを開く
2. 設定タブ →「ドライブ同期」に **同じクライアントID** を貼り付ける
3. 「Googleにログインして同期」→ **同じGoogleアカウント**でログイン
4. 「✓ 同期完了」と出れば、1台目のデータがこの端末にも入っています

以降は記帳するたびに自動で同期されます(アプリを開き直したときだけ、同期ボタンをもう一度押してください)。

## ステップ3: 家計簿として使い始める前の初期設定

1. **設定タブ → カード**: 各カードの締め日・支払日を確認。初期値はカード会社の一般的な規定なので、
   実際の明細と違うカードがあれば直してください
2. **設定タブ → 固定収支**: 給与・ローン・月謝などの金額を最新にする(Excelの2026年4月の値が入っています)
3. **予測タブ**: 「現在の生活口座残高」を入力すると、6ヶ月先までの残高予測が出ます
4. **取込タブ**: マネーフォワードMEのデータを取り込む場合
   - パソコンのブラウザで https://moneyforward.com/ にログイン
   - 「家計簿」→ 月を選ぶ → **「ダウンロード」→「CSVファイル」** で保存 (プレミアム機能)
   - アプリの取込タブでそのファイルを選ぶ → カテゴリを確認して「取り込む」
   - 月に1回くらいの取り込みでも、重複は自動で除外されるので安心です

## うまくいかないとき (よくあるつまずき)

| 症状 | 原因と対処 |
|---|---|
| アプリのURLを開いても404 | GitHub Pagesの設定(1-2)がまだ。SourceがGitHub Actionsになっているか確認。設定直後はActionsの完了(1-3)も待つ |
| 同期で「アクセスをブロック: …テストを完了していません」(access_denied) | ログインしたアカウントがテストユーザーに入っていない。2-3に戻ってそのGmailを追加 |
| 同期で「エラー 400: origin_mismatch」 | 2-4の「JavaScript生成元」のURLが違う。`https://kurigorira.github.io` (末尾スラッシュ・パスなし)になっているか確認。直してから反映まで数分かかることあり |
| ログインのポップアップが出ない | ブラウザがポップアップをブロックしている。アドレスバーの通知から「許可」する |
| 端末を変えたらデータがない | ドライブ同期を設定していれば設定タブから同期。していなければ旧端末で「バックアップを保存」→ 新端末で「ファイルから復元」 |
