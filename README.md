# 栗原家 家計簿

Excelでの家計管理を置き換える、日々の記帳・カード管理・資金予測のためのWebアプリです。
サーバー不要でブラウザだけで動き、データは端末内(IndexedDB)に保存されます。

## できること

- **記帳** — 金額・カテゴリ・支払方法を数タップで入力。よく使う組み合わせはテンプレートとして自動表示
- **収支** — 月ごとの収入・支出・収支、カテゴリ別内訳(円グラフ)、予算との比較、直近6ヶ月の推移
- **年度表** — Excelの収支シートと同じ「4月始まり・カテゴリ×月」のマトリクスを自動集計
- **カード** — 各カードの締め日・支払日から「今いくら使っているか」「何日にいくら引き落とされるか」を自動計算。月ごとの引落カレンダー付き
- **予測** — 固定収支(給与・ローン・月謝など)+カード引落+変動費の平均から向こう6ヶ月の残高を予測
- **取込** — マネーフォワードMEの家計簿CSVを取り込み(Shift_JIS対応・重複除外・カテゴリ自動推定と学習)
- **設定** — カテゴリ/予算・カードの締め支払日・固定収支の編集、JSONバックアップ/復元

初回起動時に、これまでのExcel(収支表)の項目をもとにしたカテゴリ・カード13枚・口座・固定費が登録済みの状態で始まります。

## 使い方

```bash
npm install
npm run dev      # 開発サーバー
npm test         # ロジックのテスト
npm run build    # 本番ビルド (dist/)
```

`main` ブランチにマージすると GitHub Actions が GitHub Pages へ自動デプロイします
(リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください)。
スマホではブラウザの「ホーム画面に追加」でアプリのように使えます。

## データの注意

- データは**この端末のブラウザ内にのみ**保存されます。設定タブから定期的にJSONバックアップを保存してください
- マネーフォワードとの連携は、マネーフォワードME(プレミアム)の「家計簿データのダウンロード(CSV)」を取込タブで読み込む方式です
- カードの締め日・支払日の初期値は一般的な規定に基づくため、実際の明細と違う場合は設定タブで修正してください

## 技術構成

React 18 + TypeScript + Vite / Dexie (IndexedDB) / Recharts / Vitest
